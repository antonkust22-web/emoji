SONATA VPN — анимированный набор кастомных эмодзи (33 шт.)

Файлы: WEBM VP9 с прозрачностью, 30 fps, 2 сек, бесшовный цикл, без звука, каждый меньше 256 КБ.
  webm_512/  — 512×512 (под требование @Stickers)
  webm_100/  — 100×100 (родной размер кастомных эмодзи, использует upload_pack.py)
  manifest.json — какой файл к какому эмодзи привязан
  preview.png   — общий вид набора

КАК СОЗДАТЬ НАБОР
Вариант 1 (быстро, скриптом): python3 upload_pack.py ТОКЕН_БОТА ВАШ_TELEGRAM_ID
  Набор создастся от имени бота (sonata_anim_by_<логин>) и в emoji_ids.json сохранятся ID эмодзи.
  Старый набор t.me/addemoji/SonataVPN скрипт изменить не может (он создан не ботом) — это будет новый набор.
Вариант 2 (вручную): @Stickers -> /newemoji -> «Видео» -> загружайте файлы из webm_512 по одному,
  для каждого указывая эмодзи из manifest.json.
